# Cybersecurity Internship — Elevate Labs

This repository contains my practical assignments and learning outcomes from the **Cybersecurity Internship at Elevate Labs**. The projects focus on developing foundational cybersecurity skills through hands-on exercises, network analysis, security tools, and technical documentation.

## 📌 About This Repository

Each task is maintained in a separate directory containing its documentation, relevant scan reports, screenshots, and supporting files.

The objective is to understand how cybersecurity tools are used to examine systems and networks, interpret technical findings, and identify areas that may require further security review.

## 🛠️ Tools and Technologies

* **Nmap:** Network discovery, port scanning, and service detection
* **Terminal:** Executing commands and analysing results
* **Git and GitHub:** Version control and project documentation
* **macOS:** Environment used for practical exercises

## 📂 Tasks

### Task 1 — Network Port Scanning

Used Nmap to scan my local network and inspect services running on my own Mac.

**Activities performed:**

* Discovered active hosts on the local network.
* Performed TCP SYN scanning to identify port states.
* Used service version detection on localhost.
* Recorded and reviewed scan results.
* Documented observations and security considerations.

**Folder:** `Task-1-Network-Port-Scanning/`

**Key findings:**

* Identified open, closed, and filtered TCP ports.
* Observed services associated with DNS, HTTP, HTTPS, and local applications.
* Identified a Node.js Express service on port 3000 and AirTunes-related responses on ports 5000 and 7000.

Open ports do not automatically indicate vulnerabilities. Further investigation would be required to assess their security implications.

## 🎯 Learning Objectives

* Understand basic network reconnaissance.
* Learn how TCP port scanning works.
* Interpret Nmap scan results.
* Understand the difference between open, closed, and filtered ports.
* Practise responsible and authorised security testing.
* Document technical findings clearly.

## 🔐 Responsible Use

All scanning activities should be restricted to systems and networks I own or have explicit permission to assess. Reports and screenshots published in this repository should be reviewed to avoid exposing personal device information or other sensitive details.
